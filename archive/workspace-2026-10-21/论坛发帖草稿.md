## 代码时间机器：从打孔纸带到 AI 编程，用 6 个时代回答“Build 是什么”

1024 是开发者的节日。今年我没有做一个“更快的工具”，而是做了一台可以回到过去的终端。

它叫 **代码时间机器**：你打一张卡、让寄存器相加、用管道抓出错误、拼一个主页、把应用送上云、再给 AI 下一次指令。走完六站，它会告诉你：你最适合哪个时代。

### 一句话

> 一台可以回到六个编程时代的终端。每个时代留下一枚印章，最后生成一份属于你的《Builder 时间旅行档案》。

### 为什么做这个

今年的作品秀里，有很多很棒的工具、游戏和节日玩具。我想换一个角度：**如果把“工具的变化”本身做成一个可玩的作品，会是什么样？**

从 1804 年的打孔卡，到 2026 年的 Prompt，工具一直在变。但每一代 Builder 做的事其实很像：把脑子里的东西，变成别人能用、能看见、能继续改的东西。

所以有了这六个时代。

### 怎么玩

全程 6 站，每站 30-60 秒，不需要读说明书。六个时代是六间不同的房间：织机工坊、ENIAC 控制台、电传机、90 年代桌面、云仪表盘、AI 对话窗。目标写在房间里，不写在说明书里。每一站也有自己的声音。

**限时 1024 秒**——和节日同数字。从按下“启动时间机器”开始，顶栏右侧倒数。时间用完，机器不会判你失败，而是进入 **Agent 接管**：一个 AI 光标逐关把剩下的站接完，档案里如实写明哪几站是它替你 Build 的，并把接管行为算进“指挥”维度。你也可以随时点“我来”把控制权拿回去。

另外，**每一站第一次答错都会弹出一张 CHEAT CODE 卡**：可以让 Agent 自动帮你填这一关，代价是档案里那一站会标成“代打”；不想用就点“我再想想”，同一关不会再劝你。这个设计是故意的——它把“AI 到底该在什么时候接手”变成了玩家自己的一个选择，而不是一个背景设定。

1. **1804 · 打孔卡**
   用 5 位二进制打出你代号的首字母。孔位不对，织机不会说谎。

2. **1945 · 寄存器**
   从 6 条指令里选 4 条，让寄存器 `A + B` 输出 7。机器只认识顺序，不认识你的意图。

3. **1972 · Unix / C**
   日志里既有 500 错误、404 错误，也有一条 200 但耗时 500ms 的记录。用 `grep` + `wc` 的管道，把真正的 500 错误数出来。

4. **1991 · Web**
   添加标题、简介、链接和访客计数器，选一个背景，发布你的第一个个人主页。留言簿和跑马灯是加分项。

5. **2007 · 移动 / 云**
   预算 $9。每台服务器 $2，容量 300；缓存 $1，负载降低 40%。让 1024 个请求平稳落地，超时要少于 10 个。

6. **2026 · AI**
   这一站的提示词由你来写。AI 只提问，不给答案；写够 4 个字才能生成，选目标和风格，拿到一份 4 步 Build 计划，再决定要不要采纳。

每站完成后，会收到一张 **时代档案卡**：一段 80–120 字的史料、一张该时代的程序化插图，以及出处链接。它不是通关后的总结，而是每一站给你的一个“原来如此”的注脚。

> AI 时代是**本地生成模拟**，不调用真实大模型，也不消耗 API Key。这样作品可以离线运行、零成本、可复现。它模拟的是“把一句话拆成可执行计划”的体验，而不是假装接了一个模型。

### 走完之后

你会得到：

- 一个 Builder 类型（打孔卡匠人 / 寄存器魔术师 / 网页炼金术士 / Prompt 指挥家 / 机械诗人 / 系统翻译官 / 产品炼金术士 / 像素工匠 / 全栈指挥家 / 架构驾驶员 / 时间旅行者）
- 一张四维雷达：手工、底层、表达、指挥
- 六站的时代适配度，以及“最适合你的时代”
- 一张 1080×1440 的可下载海报
- 一个可分享的结果链接，朋友打开可以看到你的档案

数据只保存在浏览器里，不上传，不需要登录。

### TRAE 在创作中的作用

> 这一段必须写你**实际使用 TRAE** 的过程。下面 3 条是建议你真实去做的动作，不是已经发生的事。完成后把结果填进来，并保留对话截图。

建议真实完成：

1. **代码审查**：让 TRAE 审查最终代码，找出 3 个可改进点，至少采纳 1 个；记录修改前后的对比。
2. **文案生成**：让 TRAE 为其中一个时代生成 5 条文案变体，挑 1 条并改写；记录最终文案。
3. **调试 / 验收**：让 TRAE 帮你复现并修复一个具体问题；记录问题和验证结果。

填写模板：

```text
我实际用 TRAE 做了：
- 代码 / 功能：……
- 文案 / 结构：……
- 调试 / 验收：……
- 省下的时间：……
- 一个具体的前后对比：……
```

### 技术细节

- 原生 HTML / CSS / JavaScript，无框架、无构建依赖。
- 单文件、零外部字体 / 图片 / 音频 / 图标库，可离线打开。
- Canvas 2D：时间隧道、26.5 秒结尾动画（七段分镜、全程序化绘制）、六张时代档案卡插图、雷达、海报、隐藏结局粒子。
- 限时机制：1024 秒 deadline 存进 localStorage，刷新不能绕过；接管记录同样入档并随分享链接带出去。
- Web Audio API：振荡器 + 噪声缓冲实时合成，六个时代各有各的音色（打孔、继电器、电传打印、拨号上网、机房风扇、生成提示音），默认开启、可一键静音，不加载任何音频文件。
- localStorage：刷新继续；URL hash：分享结果。
- 全键盘可操作，支持 `prefers-reduced-motion`，手机 390 / 360 / 320px 已验证。
- 彩蛋：在任意页面输入 `1024`。
