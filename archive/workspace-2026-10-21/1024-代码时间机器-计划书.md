# 《代码时间机器》参赛计划书 v0.2

- 赛事：TRAE 社区 1024 狂欢周 · 玩法二「TRAE 1024 作品秀」
- 作品名：代码时间机器 · 从打孔纸带到 AI 编程
- 英文名：The Code Time Machine
- 形态：单页互动网页（桌面优先，移动可玩，单文件可离线）
- 截止：2026-10-23
- 版本：v0.2 执行版 / 2026-10-20
- 执行方式：全部开发、文案、测试、截图、交付物由 AI 完成；账号相关操作（论坛发帖、TRAE 实际使用记录）由你确认后执行。

## 0. 一句话

一台可以回到六个编程时代的终端：你打一张卡、让寄存器相加、用管道抓出错误、拼一个主页、把应用送上云、再给 AI 下一次指令；最后它告诉你，你最适合哪个时代。

## 1. 为什么是这个选题

- 约 60 个参赛作品中，叙事、历史、文化类为 0，是最明显的空白。
- 情绪玩具、身份卡、经典小游戏、工具仪表盘都已拥挤，纯工具型互动明显偏低。
- 该选题同时满足“1024 / 开发者 / Builder 生活”三个关键词，且最贴合“致敬真正的 AI Engineer”的活动主题。
- 一个页面里六次视觉切换，截图天然好看；结果可晒，评论区有话题。

## 2. 目标与成功标准

### 2.1 参赛目标

- 保底：1024 创意 Builder（1500 积分 + 名人堂展示）。
- 争取：1024 先锋 Builder（Ultra 1 个月）。
- 冲击：1024 高光 Builder（燃风 R4 键盘）。

### 2.2 作品验收标准

- 第一次打开，30 秒内知道要做什么。
- 6 个时代都能在 30-60 秒内完成，不需要读说明书。
- 完成后愿意下载海报 / 分享链接。
- 手机能玩，不崩版；断网可玩（首次加载后无外部请求）。
- 刷新可继续；分享链接可查看好友档案。
- 无外部字体、图片、音频、框架依赖。

### 2.3 发帖互动目标（截至 10/23）

- 浏览 300+，首帖点赞 20+，回复 15+。
- 评论区出现 10+ 条“我是 XX 型”的晒结果。
- 至少 3 条高质量建议 / 讨论。

## 3. 核心概念

### 3.1 叙事

你走进一台藏在 1024 号机房的旧终端。它说：

> “工具一直在变，但 Build 的人一直在。要回去看看吗？”

时间机器带你经过六个时代。每个时代留下一枚印章。回到 2026，它把你的选择编译成一份《Builder 时间旅行档案》。

### 3.2 主题句

> 从打孔卡到 Prompt，工具在变，Build 不变。

### 3.3 体验结构

启动 → 时间隧道 → 6 个时代 → 结果档案 → 海报 / 分享 → 隐藏结局（输入 1024）

## 4. 六个时代

| # | 时代 | 年份 / 关键词 | 视觉 | 交互（30-60 秒） | 产出 |
|---|---|---|---|---|---|
| 1 | 打孔卡 | 1804 提花机 / 1890 人口普查 | 米白卡纸、琥珀色、机械织机 | 用 5 位二进制在卡片上打孔，拼出代号首字母 | 专属打孔卡 + 印章 |
| 2 | 寄存器 | 1945 ENIAC / 1952 编译器 / 1972 C | 绿色磷光、CRT 扫描线、真空管 | 从 6 条指令中选 4 条并排序，让寄存器 A+B 输出 7 | 一段可运行的程序 + 印章 |
| 3 | Unix / C | 1972 贝尔实验室 | 琥珀色终端、纸带、管道 | 用 `grep` / `wc` 组合管道，从日志中统计 500 错误 | 一条可复用命令 + 印章 |
| 4 | Web | 1989 Web 提案 / 1991 第一个网站 | Y2K 早期网页、蓝底银灰、浮雕按钮 | 添加标题 / 简介 / 链接 / 计数器，拼出第一个个人主页并发布 | 一个迷你主页 + 印章 |
| 5 | 移动 / 云 | 2007 iPhone / 2010s 云原生 |  glossy 手机、云、服务器机架 | 在预算内配置服务器与缓存，让 1024 个请求平稳落地 | 一次上线记录 + 印章 |
| 6 | AI | 2021 Copilot / 2022 ChatGPT / 2026 | 深色玻璃、极光渐变、粒子 | 输入一句需求，本地生成一份 Build 计划 + 生成式海报 | 一份 AI 协作记录 + 印章 |

### 4.1 时代 1：打孔卡

- 任务：选择代号首字母 A-Z，卡片显示 5 位二进制；点击孔位打孔；读卡器校验。
- 反馈：打孔音效、齿轮转动、织机把字母“织”出来。
- 史料：1804 年提花机用打孔卡控制图案；1890 年美国人口普查使用 Hollerith 制表机。
- 失败保护：点错可撤销；3 次错误后高亮正确孔位；不惩罚到无法完成。
- 计分：手工精度为主，底层思维为辅。

### 4.2 时代 2：寄存器

- 任务：6 条指令中选 4 条并排序，让 `OUT` 输出 7。
- 指令池：`LOAD A 3`、`LOAD B 4`、`ADD A B`、`OUT A`、`SUB A B`、`JMP 0`。
- 反馈：寄存器数字滚动、单步日志、绿色终端打字机、死循环过热提示。
- 史料：ENIAC、Grace Hopper 的 A-0 编译器、C 语言。
- 计分：底层思维为主，手工为辅。

### 4.3 时代 3：Unix / C

- 任务：`access.log` 里既有 500 错误、404 错误，也有一条 200 但耗时 500ms 的记录；用管道统计真正的 500 错误数。
- 指令：`cat access.log`、`grep ERROR`、`grep 500`、`wc -l`、`sort`、`uniq -c`。
- 正确解：`cat access.log | grep ERROR | grep 500 | wc -l` → 3。
- 反馈：真实管道模拟、终端输出、错误提示“有一条 500 不是错误”。
- 史料：1972 年 C 语言；Unix 的“小工具组合”哲学。
- 计分：底层思维为主；管道越简洁分越高，错误尝试扣分。

### 4.4 时代 4：Web

- 任务：添加标题、简介、链接、访客计数器（可选留言簿、跑马灯），选择背景，点击发布。
- 反馈：早期网页风格的浏览器预览、`Under Construction` 动画、假域名 `http://<name>.1024`、访客计数器 +1。
- 史料：1989 年 Tim Berners-Lee 提出 Web；1991 年第一个网站上线。
- 计分：表达力为主；可选模块和自定义文案越多，分越高。

### 4.5 时代 5：移动 / 云

- 任务：预算 $9，服务器 $2/台（容量 300），缓存 $1（负载 -40%）；让 1024 个请求平稳落地。
- 可行解：4 台服务器（$8，容量 1200）；或 3 台 + 缓存（$7，有效负载 614 < 900）。
- 反馈：手机、云、服务器机架、实时请求/容量曲线；成功上线 / 超时报警。
- 史料：2007 年 iPhone；云原生与弹性扩容。
- 计分：底层思维 + 指挥力；成本越低、超时越少，分越高。

### 4.6 时代 6：AI

- 任务：选择目标（做工具 / 修 Bug / 讲故事）+ 风格（极简 / 复古 / 赛博），输入一句需求，生成 Build 计划与生成式海报。
- 反馈：本地模板引擎生成 4 步计划 + Canvas 生成式海报；可“再生成一次”；海报成为最终档案的视觉底。
- 说明：不接真实大模型 API，保证离线、零成本、无 Key；帖子里明确写“本地生成体验”。
- 史料：2021 Copilot 技术预览；2022 ChatGPT；2026 AI 原生编程。
- 计分：指挥力为主，表达力为辅；需求越具体、风格越明确，分越高。

## 6. 技术方案

- 原生 HTML/CSS/JS；Canvas 2D；Web Audio；localStorage；无框架、无构建依赖。
- 源码结构：`index.html`、`styles.css`、`js/*.js`、`build.js`。
- 交付：`code-time-machine.html` 单文件版 + 在线 Demo + 源码。
- 状态机：6 个 era 模块，统一 `mount / complete`；进度存 localStorage；刷新可继续。
- 结果：四维雷达（手工 / 底层 / 表达 / 指挥）→ 纯类型 / 混合类型 / 时间旅行者。
- 海报：1080×1440 Canvas，六枚印章、类型、雷达、评语、日期；`toBlob` 下载。
- 分享：结果压缩进 URL hash；打开带 hash 的链接进入“好友档案”模式。
- 可访问性：全键盘、焦点可见、`aria-live`、对比度、减少动态。

## 12. 诚实说明
